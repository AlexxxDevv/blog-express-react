Приложение представляет собой страницу, на которой могут делать записи любые авторизованные пользователи.

1. Реализована регистрацию и авторизация пользователя, а также проверка JWT-токена при внесении записей на страницу
2. Запись блога содержит:
    1. Дата записи
    2. Сообщение: может содержать как текст, так и медиа (картинки или видео)
    3. Автор сообщения
3. Автор записи может редактировать или удалять запись
4. Выполнен деплой сервера для публичного доступа в облако yandex.cloud
5. Написана документация к эндпоинтам

- Используется реляционная база данных
- Express js
- TypeORM
- React
- Typescript
- Docker
- Eslint, Prettier,
- Shadcn, Tailwind
- Swagger
